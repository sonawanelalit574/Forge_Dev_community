# Forge

Professional developer community built with **Python / Flask**.

Self-text, questions, links, and polls are real post types. Option buttons switch the composer panes and filter the feed.

## Run

```bash
cd dev_community
python -m pip install -r requirements.txt
python run.py
```

Open [http://127.0.0.1:5020](http://127.0.0.1:5020)

Demo member: `demo` / `demo123`

## What works

- Sign in / register
- Feed filters: Latest, Top, Unanswered
- Kind filters: All, Self-text, Questions, Links, Polls
- Space buttons in the sidebar
- Composer option buttons (Self-text body, question context, link URL, poll options)
- Upvote / downvote, save, replies
- Poll voting and question solved toggle
